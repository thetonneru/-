# 良い例と採点基準

大切な仕事3つについて、できばえを自分で確かめるためのファイル。その仕事の答えを出す前に、担当のロールが読む。
採点基準は、全部「はい」なら合格。「いいえ」があれば、直してから出す。
例の中の数字は作りもので、ふみさんの実際の金額ではない。

## 1. お金の判断（照）

株・投資信託・NISA・車など、売る・買う・直すを勧めるとき。

**採点基準**
1. 結論が1つで、最初の1文にあるか
2. 口座の種類（NISAか特定口座か）と金額を確かめたか
3. 動く金額を、総資産に対する割合で示したか
4. 仮定したことと、確かめていないことを書いたか
5. 動く金額が10万円以上なら、冴のレビューが付いているか
6. 見直す条件と日付があるか
7. 買値や過去の高値を、判断の基準にしていないか

**良い例**

```
照です。**売らずに持ち続けるのがおすすめです。** 動く金額は総資産の約3%です。

**理由**
- 持つ目的（配当を受け取る）は変わっていません。会社は配当予想を変えていません。
- 今の値段で売っても買い直しても、総資産への影響は1%未満です。

**確かめたこと**
- 口座はNISAです。売っても税金はかかりません。

**確かめていないこと**
- 損失の大きさは、会社がまだ発表していません。

**見直す日**
- 次の決算の日です。それまでは何もしません。会社が配当予想を変えたら、その時点で見直します。

冴です。反論はありません。指摘は1つです。
- 「一時的」という会社の説明は、まだ裏付けがありません（重要度：中）。
```

**避ける例**
- 「持つ」「半分売る」「全部売る」の3案を並べて、選ばせる
- 「買値まで戻ったら売る」と勧める
- 値動きを予想する

## 2. ラウンドの振り返り（凪）

スコアカードを受け取って、その日のラウンドをまとめるとき。

**採点基準**
1. 最初に一言の総括があるか
2. 基準値と比べた表があるか
3. 良かった点を、崩れた点より先に書いたか
4. ダボ以上のホールの原因を、ペナルティ／ボギーオン失敗／3パットの3つに分けたか
5. 次に試すことが1つだけか。確かめる数字を1つ決めたか
6. 施策の判定の前に、スタート（イン／アウト）と朝の練習の中身を確かめたか
7. 1ラウンドだけで、傾向と決めつけていないか

**良い例**

```
凪です。**98でした。ティーショットは良く、崩れたのはグリーンの上です。**

| 指標 | 今日 | 基準値 | |
|---|---|---|---|
| ダボ以上 | 7ホール | 8.6 | 良い |
| ボギーオン | 10/18 | 11.2 | やや悪い |
| 3パット | 5 | 3.6 | 悪い |

**良かったこと**
- フェアウェイを外した4ホールとも、2打目でフェアウェイに戻せていました。

**崩れたところ**（ダボ以上7ホールの原因）
- ボギーオン失敗4、3パット3、ペナルティ0でした。
- 3パット5回のうち4回が、最初の9ホールでした。

**施策の判定**
- 朝の練習グリーンは、決めた内容と違ったので、今回は判定に数えません。

**次のラウンドで試すこと（1つだけ）**
- 朝の練習グリーンで、決めた内容（5m・10m・15mを3球ずつ）をそのままやります。
- 確かめる数字は、最初の9ホールの3パットの数です。
```

**避ける例**
- スタートを確かめずに「後半に崩れた」と書く
- 次に試すことを3つ並べる
- 1ラウンドの数字で「この施策は効果なし」と判定する

## 3. 出典つきの報告（澄の週次レポート、慧の調べもの）

Webで調べたことを、ふみさんに報告するとき。

**採点基準**
1. 要点が一言で、最初にあるか
2. 項目ごとに、確度と出典のリンクがあるか
3. 出典が1つだけのものを「未確認」としたか。元が同じ記事を、別々の出典として数えていないか
4. 見つからなかったことを、正直に書いたか
5. ふみさんの仕事や生活で使える点を、1行添えたか

**良い例**

```
澄です。**今週の大きな動きは2件です。確度が高いのは1件です。**

1. ◯◯社が新しいモデルを公開しました
   - 文章を出す速さが上がり、料金が下がりました。
   - 確度：高（公式の発表と、大手メディア2社の記事が一致）
   - 出典：公式ブログのリンク、記事のリンク
2. ◯◯に新しい機能が付くという話があります
   - 確度：未確認（出典はまとめ記事1件のみ）
   - 出典：記事のリンク

**見つからなかったこと**
- ◯◯の料金は、公式の情報が見つかりませんでした。

**仕事で使えそうな点**
- 1の新しいモデルは、商談の練習の相手に向いています。
```

**避ける例**
- 出典のリンクを付けずに出し、あとで「ソース示して」と言われる
- まとめ記事にしか出ていない話を、事実として書く
- 見つからなかったことを書かずに、分かったことだけを並べる
