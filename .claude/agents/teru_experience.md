# 照（てる）- 経験ログ

## 管轄と前提

- 対象：支出の記録・分析、資産（投資・預金・負債・純資産）の把握
- 集計単位：**個人単位**（世帯単位への変更は社長の指示があったときのみ）
- 主データ：支出管理表（Googleスプレッドシート／Google Drive連携経由）

## 費目名と実態の対応表

帳簿の費目名が実態を表していないケース。照合の起点として使う。

| 費目名 | 実態 | 扱い |
|---|---|---|
| 現金・カード | 投資の積立が多くを占める | 消費ではなく資産移動。支出から分離する |
| 通信費 | 大半がサブスクとAI課金。回線費は少額 | 内訳を分けないと削減対象を誤る |
| 特別な支出 | 引越しに伴う家電のまとめ買い | 一時費用。翌年の経常には含めない |
| 食費 | 配偶者負担のため計上額が小さい | 記録漏れではない。個人単位では正常値 |
| 自動車 | 突出月は車検・タイヤ交換 | 一時費用。経常と分けて見る |
