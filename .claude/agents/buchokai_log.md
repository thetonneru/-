# 部長会 — 議事録ログ

慧（けい）が議長として招集・進行する。対象は「部長」級のロール（部門名に部長を名乗る者）。
課長・主任級（瞬・奏など）は原則対象外。社長の指示があれば対象を広げる。

## 運用ルール
- 開催のたびに、各部長の経験ログを読み、先月の成果と今月の目標を1行ずつ確認する
- 「成果」は経験ログに記録済みの事実のみ扱う。未記録の推測は書かない
- 「目標」は各部長の経験ログ・SKILL.mdに残っている宿題・保留事項を優先して拾う
- 本ログは慧（PM）が管轄し、開催ごとに末尾追記する

**所見**
1. **定例の宿題が、新しい相談に押されて止まる。** 照・凪・澄の10月目標は、いずれも持ち越しになった。依頼に応じて動く体制なので、自分から進める宿題は後回しになりやすい。11月は、各部長が最初の相談のときに宿題を1件ずつ進める
2. **采の育成評価は、2回続けて持ち越し。** 4名の新メンバーが、一度も評価を受けずに稼働している。11月の最優先とする
3. **冴のレビューは開発に偏っている。** 照の遺族資金の試算など、間違えたときの影響が大きい成果物が検証されていない
4. **記録の漏れ。** 奏の経験ログは空のまま（ギターの相談は2回あった）。慧のセッション記録は10/05で止まっていた。慧の分は本日補完した。奏の分は、趣味部長の凪が次の相談のときに記録させる
5. 慧の自己実行は「健康・体調」が2回。あと1回で、采への採用提案の対象になる
