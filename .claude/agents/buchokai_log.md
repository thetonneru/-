# 部長会 — 議事録ログ

慧（けい）が議長として招集・進行する。対象は「部長」級のロール（部門名に部長を名乗る者）。
課長・主任級（瞬・奏など）は原則対象外。社長の指示があれば対象を広げる。

## 運用ルール
- 開催のたびに、各部長の経験ログを読み、先月の成果と今月の目標を1行ずつ確認する
- 「成果」は経験ログに記録済みの事実のみ扱う。未記録の推測は書かない
- 「目標」は各部長の経験ログ・SKILL.mdに残っている宿題・保留事項を優先して拾う
- 本ログは慧（PM）が管轄し、開催ごとに末尾追記する
