# 仕事ごとのモデルの使い分け表

ふみさんが、どのモデルで頼むかを決めるときに見る表。2026-11-12 に作った。
分け方のもとは「普段はOpus 5.5、難しい大仕事だけFable 5.2」という公式の目安。
ふみさんが使っているのはOpus 5.5とFable 5.2なので、ほかのモデルは載せていない。

| 仕事 | モデル | 考える深さ |
|---|---|---|
| 毎日の相談（練習メモ、スクショの質問、体調、身だしなみ） | Opus 5.5 | 標準（Medium） |
| 家計簿の転記、サブスクの確認、カレンダー登録 | Opus 5.5 | 標準（Medium） |
| ゴルフのラウンドの振り返り | Opus 5.5 | 標準（Medium） |
| 定期実行（週次AIレポート、月次の資産レビュー、部長会） | Opus 5.5 | 標準（Medium） |
| 旅のしおりなどのチェック | Opus 5.5 | 標準（Medium） |
| 10万円以上のお金の判断（株、車、NISA） | Opus 5.5 | High |
| アプリやゲームを作る | Opus 5.5 | High |
| 何日も迷っている判断を、根本から考え直す | Fable 5.2 | High |
| 前提が多い長い試算（遺族資金、来年の投資計画） | Fable 5.2 | High |
| 規格の根拠までたどる深い調べもの | Fable 5.2 | High |
| AI環境の整理、チームの作り直し | Fable 5.2 | High |

## 覚えておくこと

- モデルは `/model` で切り替える。切り替えるのはふみさん。
- この会話に届く定期実行（週次AIレポート、月次の資産レビュー、部長会、照の予約）は、この会話のモデルで動く。Fable 5.2のままにしておくと、定期実行もFable 5.2で動き、使用量を多く使う。
- Fable 5.2を使い終わったら、Opus 5.5に戻す。
