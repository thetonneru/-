# ふみさん用のテンプレート

ふみさんがコピーして、空いている所を埋めて送るための型。全部を埋めなくてもよい。
ロール側は、テンプレートを使っていない依頼もそのまま受け付け、足りない項目だけを1回でまとめて聞く。

## ゴルフのラウンド報告（凪）

```
ラウンド報告
コース：
スタート：イン／アウト
朝の練習グリーン：決めた内容でやった／別の内容／やっていない
天気と風：
気づき：
（スコアカードの写真を付ける）
```

## ゴルフの練習メモ（凪）

```
練習メモ
やったこと：
気づき：
次のラウンドで使いたい：はい／まだ
```

## チェックの依頼（冴）

```
チェックして
重視すること：（例：時間の余裕／費用／スマホでの見やすさ）
前の版から変えた所：
わざと外したもの：
```
